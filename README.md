🔑 Password Generator

A beginner-friendly Python cybersecurity project that generates random passwords based on user-specified requirements.

🧠 About the Project

I built this project to practice Python programming while exploring the importance of creating strong, unpredictable passwords.

The user can specify their desired password length, and the program generates a random password using different character types.

⚙️ Features

- 🔢 Custom password length
- 🔤 Letters
- 🔢 Numbers
- 🔣 Special characters
- 🔐 Random password generation
- 💻 Terminal-based interface

🛠️ Technologies

- 🐍 Python
- 💻 Terminal / Command Line

▶️ How to Run

Run the Python file from your terminal:

python password_generator.py
